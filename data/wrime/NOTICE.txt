Processed splits
  The 9-class single-label splits used in this work (train.tsv, dev.tsv, test.tsv) are not included.
  They are adapted material, and the licence does not allow sharing adapted material. The same applies
  to any file that would contain WRIME sentence text, so prediction files in this package hold row
  indices, gold labels and probabilities only.

  To recreate the splits exactly (standard library only, a few seconds on CPU):

    python tools/build_wrime.py

  This reads source/wrime-ver2.tsv and writes data/wrime/train.tsv, dev.tsv and test.tsv
  (28,360 / 2,408 / 2,347 rows) together with split_sizes.json. The script checks the source file
  hash and the SHA-256 of every output file against the values used for training.

  Labelling rule: for each of the eight Plutchik emotions take the exact mean of the three reader
  intensities (0-3). If every mean is below 1.0 the label is neutral; otherwise the label is the
  unique strongest emotion; rows whose strongest mean is shared by two or more emotions are dropped.
  Tabs and line breaks in the text are replaced by one space, then the text is stripped. The official
  Train/Dev/Test column is used as is.

  Alternative test protocol (edom18, used only for the comparison with that public result):

    python tools/build_wrime.py --protocol edom18

  writes data/wrime_edom18/test.tsv (all 2,500 official test rows; rounded "Avg. Readers" columns,
  Sentiment excluded; all zero -> neutral; otherwise the largest, ties broken by column order).
